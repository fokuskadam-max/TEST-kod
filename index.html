🔗 Сілтеме жасау орталығы

Бұл жерден файлды тікелей жүктеуге браузер рұқсат бермейді. Сондықтан 1 батырмамен арнайы сайт ашылады, сонда жүктеп, сілтемесін осында қоясың. Бұл 100% жұмыс істейді!
📷 1. Фотоның сілтемесін жасау
Қалай жасайсың?
1️⃣ Төмендегі көк батырманы бас → 0x0.st ашылады
2️⃣ Сол жерде фотоңды таңда → сілтеме шығады → көшіріп ал
3️⃣ Сол сілтемені төмендегі қорапқа қой → «Фото орнына қою» бас

🎵 2. Әннің сілтемесін жасау
Қалай жасайсың?
1️⃣ Көк батырманы бас → сайт ашылады → әнді жүкте → сілтемені көшіріп ал
2️⃣ Сілтемені төменге қой → «Ән орнына қою» бас

🎥 3. Видеоның сілтемесін жасау
Қалай жасайсың?
1️⃣ Көк батырманы бас → видеоны жүкте → сілтемені көшіріп ал
2️⃣ Сілтемені төменге қой → «Видео орнына қою» бас
